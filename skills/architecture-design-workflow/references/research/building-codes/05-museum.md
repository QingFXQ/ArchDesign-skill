# 博物馆建筑规范索引

按当前项目的建筑类型、总建筑面积、藏品材质、展陈方式和规划条件查条文。本页用于方案阶段定位原文及核对布置。

## 版本与适用关系

- JGJ 66-2015《博物馆建筑设计规范》适用于博物馆新建、扩建与改建。住建部第 846 号公告明确自 2016 年 2 月 1 日施行，取代 JGJ 66-91，发布时列明第 4.1.3、4.1.5 条为强制性条文。[住建部发布公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2015/art_17339_224143.html)

## 规模、总图和面积

| 条文 | 方案核对内容 |
| --- | --- |
| 1.0.3、表 1.0.4 | 历史类、艺术类、科学与技术类、综合类按藏品及基本陈列内容定。规模按总建筑面积，原表以整数平方米列示：小型不超过 5,000，中型 5,001–10,000，大中型 10,001–20,000，大型 20,001–50,000，特大型超过 50,000。接近分界时按正式面积口径复算。 |
| 3.1、3.2 | 核选址环境、集散、独立藏品进出、远期建设及室外展场的人员和展品路线。第 3.2.2 条规定新建博物馆建筑密度上限为 40%，用地控制另核红线、绿地率及规划条件。表 3.2.4 的停车配建使用“不宜小于”，按馆规模分类核对，车库建筑面积从配建计算基数中扣除。 |
| 4.1.1、4.1.2 | 公众、业务和行政分区。陈列展览区、藏品库区的建筑面积比例按馆类型、规模和工艺确定，表 4.1.2 可供参考。总体建面、功能区建面、房间净面积、楼板投影、挑空和室外展场分别核算。 |
| 地方与地块条件 | 核用地规划条件、退界、停车、绿地及相邻设施。有水岸时核实际控制线、水位、防洪标高、排水、防潮及现状护岸。扩建位置应能继续使用现有藏品运输、公共交通和消防组织。 |

## 展陈、观众与藏品

| 条文 | 方案核对内容 |
| --- | --- |
| 4.1.3–4.1.5、4.1.12 | 观众、藏（展）品、员工出入口分置，公众至行政和业务的连通处可关闭。观众、食品和垃圾的相应路线均须避开藏（展）品路线。藏品保存场所的上层及同层贴邻避开有积水风险的房间，核与藏品保存无关的管线、使用水消防房间的防水排水措施以及厨餐、垃圾等风险源。 |
| 4.1.6、4.1.7–4.1.8 | 核独立开放空间的容量与进出。画出装卸、前处理、缓冲、专用货梯及可关闭候梯间、库房及展厅的实际路径。通道不得设置台阶或门槛，采用坡道时坡度不得大于 1:20。按运输设备和展品包装尺寸核门洞、净高、转弯及荷载。 |
| 4.1.9–4.1.11、7.2.4 | 卫生间计算区分用途。陈列展览区按展厅净面积 0.2 人/m²，教育区按设计容量的 80%，按表 4.1.9 和男女各半计算洁具。餐饮、商店、报告厅及员工按各自适用规则核查。陈列展览防火分区的疏散人数按区内各展厅高峰限值求和，另核报告厅等其他用途。 |
| 4.2.1–4.2.5、5.1.1、5.4.3 | 核展厅独立关闭、布撤展、观看与通行空间。一般条件下，单跨展厅跨度不宜小于 8 m，多跨柱距不宜小于 7 m（4.2.2）。展厅净高按展品、吊挂与设备要求推导，再查馆型和展品对应条文。5.1.1 属于历史、艺术与综合类，5.4.3 属于科技馆。课程对跨度、独立厅或自然采光的要求按课程来源另列。 |
| 4.4、5.1.2–5.1.4、第 6 章 | 库房区与库前区按工艺布置。涉及第 5.1 节的项目按藏品材质分间、核珍贵藏品独立保存。按最大运输对象和实际货架查净宽、净高与荷载。温湿度、洁净、防光、防水防潮、防振和监测按藏品与保护工艺确定。 |
| 8.1、8.2、第 9 章 | 按展品及展陈要求确定采光。对天然光核直射阳光、紫外、眩光、累计曝光和低照度展厅入口的视觉适应。按展品类别核人工照明，另核环境与展品安全。 |

## 防火与高差

- JGJ 66-2015 第 7.1.2 条的博物馆耐火等级基线为二级。地下或半地下建筑（室）、高层建筑、总建筑面积大于 10,000 m² 的单层或多层建筑，以及主管部门确定的重要博物馆，满足其中一种情形时要求一级。第 7.1.3 条要求高层博物馆按一类高层民用建筑的防火规定设计。建筑高度和高层分类按各自的适用条文与实际标高认定，单独记录规模类别和耐火等级。
- 展陈和藏品库按第 7.2 节结合通用规范，分开核防火分区、藏品火灾危险性、房间分隔、门、楼梯及疏散。跨层大厅和展厅在剖面标出敞开连通范围、分隔措施、疏散核和待专业核实的烟控条件。
- 场地图逐段核无障碍到达、客梯、观景、卫生间与室外高差，藏品运输坡道按专门条文另核。概念水位、风景视线与法定控制条件分别标注。

博物馆的规模分类、耐火等级、结构跨度、展厅净高和项目任务书分别记录。建筑类型、展品和运营条件改变时随方案重查。做功能与空间推演可用[博物馆类型方法](../../methods/museum-design/guide.md)，做专项自查可用[规范检查方法](../../methods/building-code-check/guide.md)。

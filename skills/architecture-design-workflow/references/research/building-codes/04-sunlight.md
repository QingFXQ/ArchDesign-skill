# 日照、天然采光与建筑间距

按本项目所在地、建筑使用类别及相邻敏感用房查原文。日照时数、漫射天然采光和防火间距各有独立的计算对象、适用条文与图面。

| 问题 | 先查资料 |
| --- | --- |
| 住宅日照 | 《住宅项目规范》GB 55038-2025、《城市居住区规划设计标准》GB 50180-2018 和项目所在地有效规划规定。逐条核替代、废止及过渡规定。 |
| 学校、幼儿园、医疗和养老等 | 对应建筑类型现行专用标准、通用规范与当地要求。确认被遮挡对象的受保护房间或场地。 |
| 计算模型与参数 | 《建筑日照计算参数标准》GB/T 50947-2014 与项目当地认可的计算规则。 |
| 室内天然采光 | 《建筑环境通用规范》GB 55016-2021、《建筑采光设计标准》GB 50033-2013 仍适用条文及建筑类型要求。 |
| 防火间距 | 先核建筑性质、高度和耐火等级，再查[防火索引](01-gb55037-fire.md)所列现行规范。 |

先记录坐标、标高、遮挡范围、现状与规划建筑，再按适用规则确认标准日、真太阳时、计算点、有效时间带和计时方法。对比调整前后的受影响窗位与场地。单时刻阴影图可找风险，合规判断需要符合当地要求的日照计算。

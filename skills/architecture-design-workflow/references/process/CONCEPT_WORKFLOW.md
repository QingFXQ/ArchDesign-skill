# 任务、案例与概念研究

将任务书拆成硬约束、软目标、交付要求和未知项。核场地边界、高差、朝向、到达、环境和运营时段；事实、解释、推断分别记录。核心建筑问题包含具体对象、冲突、来源、边界与可观察的成功状态。

用本 Skill 的设计案例工具按问题查来源、平剖及适用条件。保留案例 ID、文件、来源 URL、索引版本/hash、命中章节、可迁移操作、差异与项目验证；无命中如实登记。

概念差异来自场地嵌入、路径、庭院、竖向序列、功能组织、结构原型或整体形式构成，不是换名字或换皮。以[建筑空间设计](../methods/concept-design/spatial-composition-theory.md)为创作参考，按需读[园林空间设计](../methods/concept-design/garden-space.md)、[草图与建筑表现](../methods/concept-design/sketch-and-representation.md)及[类型设计资料](../methods/concept-design/building-type-study.md)。先用粗略容量和真实比例草图比较核心空间、组合及整体构成，再推进完整房间划分；依据实际图面迭代。每个候选说明场地、功能、流线、剖面、体量、空间体验以及收益与代价，用示意图解释。按任务与用户偏好决定候选数量，不机械追加已被否决的方向。获得授权后可开展候选试深化。用户最终选择后记录原话、冻结范围和可调整范围。

细节按需读 [概念方法](../methods/concept-design/guide.md)、[方案方法](../methods/scheme-development/guide.md) 和 [案例证据](../RAG.md)。

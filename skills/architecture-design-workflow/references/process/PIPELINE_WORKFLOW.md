# 连续建筑设计流程

从当前任务直接进入设计、制图或排版。下表用来按需找做法。项目已有成套交付和版本记录需求时，可查[项目状态](../project-state.md)。

| 阶段 | 输入与实际工作 | 可审核成果与质量门槛 |
| --- | --- | --- |
| research 任务与研究 | 原始任务书、场地、交付约束；查案例来源和当前适用规范 | 硬约束/目标/未知项、可靠坐标标高、案例方法证据、规范适用性记录 |
| concept 概念 | 从实际设计问题及案例图面出发，试有实质差异的空间策略 | 总图/功能/流线/关键剖面示意和收益代价；用户选择或修改方向 |
| scheme 深化 | 同步总图、全层功能、结构概念、平剖和运营 | 面积口径闭合、跨层路径连续、楼梯洞口支承成立；技术问题与审美都可审阅 |
| production 工程制图 | 在授权范围内先做原生代表区再扩展；增量更新标注视图 | 原生对象和真实洞口、标高/轴网、平立剖和三维同版；用户确认关键方案及图纸范围 |
| visualization 建筑表现 | 校验导出几何、坐标和相机；Blender 光材质与真实底图 | 低成本机位预览；有必要时用户选机位；润色前后建筑事实一致 |
| presentation 分析排版 | 真实分析、整套案例研究、毫米尺寸预案、字体线色统一 | 纸幅容量/比例/字高成立；查看整套、整板、打印局部与跨图关系 |
| delivery 检查交付 | 注册同版 PDF 与原生可编辑源、真实打开复验 | 自动检查、视觉评估、宿主验证及用户对具体版本的确认分列；缺项不宣称完成 |

## 用户决策

用户保留概念取舍、主要方案改变、冻结范围、表现方向和最终验收权。只在实际分歧需要决定时提供具体可比较成果；已明确授权的普通可恢复工作连续推进。用户明确要求先收集反馈时仅记录。不得把局部喜欢、可开始画图或工具成功记成完整方案批准。参考中 Gate A/B/C/D 分别仅指概念、方案、图纸、机位的用户决定，不构成独立执行系统。

## 失败与返修

场地事实缺失：标注范围，继续独立研究；不编造边界。语义检索失败：auto 报告原因并回退 baseline，显式 semantic/hybrid 失败直接报告。软件不可用：推进资料和预案，标记宿主未验证，不伪造模型。写入失败：检查活动文档、事务、模态、保存和恢复点，禁止盲目重放或强杀。表达错误修视图，模型错误修原生对象，设计错误回当前方案协调，更新所有受影响图件并使旧检查失效。

## 每轮核查

比较固定同尺度平面、关键剖面、多向轴测及必要人视点。重点看功能、结构、主要交通和空间美感，家具解决堵门、穿墙和主路阻断。统计与零警告不能代替实际看图。规范原始记录是研究线索，使用前核当前适用版本与官方依据。

# 视觉实验

## 目的与对照条件

| 目的 | 证据 |
| --- | --- |
| 空间氛围 | 实际模型、镜头和材料，人工照明及配景可以加入并注明 |
| 自然光定性 | 固定几何基线下，真实太阳与天空产生的方向、阴影、近远段明暗 |
| 相对亮度 | 同相机、构图、曝光、材质和色彩变换，记录分析的区域与取样方式 |
| 实际照度及规范 | 专业方法的绝对标定、反射率、时段／气象、传感器和适用标准；另做专业模拟 |

先把侧窗、光井、高侧窗、顶部采光、遮阳或反射导光中的一个问题说清。固定机位与曝光，让实验构造在同一源场景启闭。优先看关键剖面和多处可能受影响的表面。透明玻璃、粗糙度与反射率应真实核实，统一曝光前检查看得清暗部且亮部未饱和。定性图像和像素值不能推为照度。缺乏有辨识度的问题时，用基本实际视图完成。

## Blender 批量工具

在 Blender 中启用 Cycles，后台执行。需支持 AgX、物理天空及 glTF 等所用导入器。当前验证的是 Blender Python 5.3 系列。输入为 `schema: 1`、`units: "m"`、`datum`、`mode`，详见[渲染配置样例](../assets/render-study.json)，需换成本项目的源文件、坐标和试验对象。

    blender --background --python-exit-code 2 --python scripts/render_study.py -- config.json study-output

`history` 各案可取 .blend 或 .glb；共用外部固定机位，室内可在 `interior_poses` 中提供同镜头的 `eye/aim/reason`。灯光按局部坐标指定从场地指向太阳的 `sun_direction`，共同设定太阳能量和天空强度。各机位的曝光固定。旧人工灯会关闭。可选中性 `neutral_material` 设置基础材质；用 `keep_materials` 显式保留玻璃和基准材料名称，各案应确保这些材料本就是可比的。模型对齐、环境、日照当地校准及人体模型由制作者在可比源或副本预置，脚本不会生成地形、人物或替模型纠偏。

`daylight` 全案指向同一模型和场景，使用同一相机、光照和材质。只改变同一组明示几何对象的 `visibility`（真表示隐藏）。方案使用相同的对象列表，值不同。先核命名对象只承担要测的构造功能。相机和光照参数写入 `study.json`，记录源 SHA-256，渲染到新目录，历史模型保持只读。计算环境和质量有要求时再选择渲染尺寸。查看实际 PNG、相机记录和模型剖面。

## 可选生图

在方向缺乏、核心空间需要视觉探索，或已有明确反馈问题时启用。开放创意可以放宽主体限制，用结果找构成规则。保真表现使用受约束的实模基底，明确必须保留的场地、几何、标高与构造。图像作为概念或表现证据标记，与实模图分开。

真实问题 → 生图试验 → 实际读图 → 选择有空间价值的动作 → 写回实模 → 同机位重渲染。比较主次与空间整体，上下层与不同机位的一致性需由实模验证。未能找到可验证的空间改进时停止重复试验。项目可完全使用实际白模、剖面与实体样片完成。

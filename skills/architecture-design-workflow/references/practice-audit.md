
# 真实项目使用审计

证据来自一座课程文化建筑的一草 V1–V8。审计只读检查了任务书抽取、教师案例资料、项目记录、各版模型与比例图、面积和地形表、重点源码、图像提示与反馈、评图和历史横评图册。原始资料及生成图保留在项目目录。早期零散补丁和工作草稿主要见本机临时脚本，现存脚本可核具体机制，不能据此重建每一轮完整源码快照、全部修改命令或未归档的原生中间文件。教师口头反馈按现有用户转述与项目记录核对，可复述要求，无法独立证明课堂现场。早期部分 GLB 只含封实体量，室内通过原平剖理解。个别概念停留于图片。原始试验的人工投入时间、检索次数、生图成本与完整调用日志没有统一计量。

## 实际回归与限制

- 基线 Skill 的检索与版面测试 16 项均通过。新增 23 项自动测试全部通过。小办公楼和合成地形覆盖净面积约束、阶段／暂停、几何、开口、切削、挖填和路径。已执行 Blender 宿主烟测，覆盖网格保存重开、开闭构造双渲染、源模型哈希和拒绝非同机位的自然光实验。
- 本机用 V7／V8 实际脚本只读导出各层控制面、庭院及挑空、房间几何、净用内缩和预算，重算建面、展厅及交通，均对上原表的 0.02 m² 读数范围。V8 有原脚本按毫米取整产生的边界细缝，检查采用源精度并明示细微差额。旧数据留在工作区外。另重算 V8 已归档 36 段路径，坡度差在坐标取整造成的 0.11 个百分点内。
- 只读重算三组 V5、V8 归档地形。两个压缩网都有一个完全等值重复顶点及一个零投影面，只在临时输入中归并。旧算法可复现旧表。更正后的挖方比原表多约 7–9 m³，几何填方多约 11–40 m³；分组实际量及采用口径仍属项目数据。检验正负积分差与独立有符号积分一致。参数敏感性仍来自项目假设。
- 在同一 Blender 参数下重渲染三种实际历史方案的两类机位，覆盖原生 Blend 和归档 GLB，源哈希一致。此轮验证 Windows 环境中的 Blender Python 5.3 系列；未覆盖所有 Blender 版本、Revit／CAD／SketchUp／Photoshop 宿主、专业光度或工程合规。既有资源适配器通过原用例，外部私有库与模型服务连接不作为前提。
- 公共技能只含原创方法、脚本和合成例。整仓只读扫查仍有遗留本机路径、局域网地址、疑似凭据字符串以及大模型和图资，范围在本次 Skill 之外。命中需由维护者确认用途及传播权，部分可能是示例文本。公开整个旧仓库前应单独处理。审计未访问凭据内容来验证其有效性。

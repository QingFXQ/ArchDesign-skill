# 立面、群体构成与外部空间操作

依据彭一刚《建筑空间组合论》第二版（1998）。第四轮研读范围为原扫描本PDF288—354页的整体浏览，重点放大阅读PDF288—291、297—306、314—315、328—332、337—341、343—354。以下为原创设计方法转译；页码以印刷页为主（本范围PDF页序=印刷页+9）。不声称逐字读完所有图版，不上传原书图像。历史案例的工程尺寸及构造不由缩略图推断。

使用本手册时，先明确一个实际形体、立面或场地构成问题，选少量操作画草图、修改几何、观察变化。无需全部执行，不增加固定报告、评分或测试。与[空间与体形操作手册](spatial-operations.md)、[园林空间](garden-space.md)配合。

## F01 从面上的均衡转向空间内的均衡

**来源**：图111、112，印刷279—281页。原书比较对称、非对称及动态均衡，并指出现代建筑在运动中各个立面关系不断变化，不能只凭一个正立面判断均衡。

**操作**：
- 在同一建筑容量下比较轴向对称、偏心主量体与从属体量相平衡、多个有方向的体量相互联系。比较宽度、高度、位置、距离及可见面积，不把视觉均衡简化成数值重心。
- 在平面上标道路转角、入口前庭、沿边步行和主要远景视点。以相同焦距及真实视高观察主次关系是否在接近过程中保持可理解性。
- 对于一张立面好看但斜向视角失衡的方案，优先改变体量位置、连接体、边界、屋盖或视线关系。不要用相机裁切掩饰。
- 动态变化可以是目的；不同视角出现不同重点未必有问题。对称也不是必须淘汰的传统形式。

## F02 外轮廓线与整体剪影

**来源**：图113，印刷282页。原书列举传统建筑屋顶、塔状构件和现代体量的阶梯、起伏及顶部变化。

**操作**：先在场地主要视角输出无材质剪影及屋面投影，再比较统一水平边界、主体局部抬升、渐变/阶梯式高差、少量重点与连续次要轮廓。先明确真实内部层高及结构需求；也允许出于构成或精神目标作适度形体调整。检验远景是否形成清晰主从，近景是否具有合理尺度。避免每个体块随机升降、每个房间各配一片屋顶；有意保持平直轮廓同样可能成立。

## F03 虚实与凹凸：两个相对独立的变量

**来源**：图117，印刷288—291页。原书以博物馆、电影院、旅馆、办公等建筑说明，虚实和凹凸的对比可以富于变化，仍应成为统一整体。图中博物馆及电影院采用大面积实体界面，以少量开放部分突出重点；旅馆和交通建筑示例有不同程度的虚实穿插。

**操作**：
1. 先从平面、剖面明确实际需要开敞、封闭、采光、避光、观景、通行、遮蔽的区域，画仅有两三种色块的立面草图。
2. 对同一功能容量比较实为主且局部开敞、上实下虚、连续实体框架内退、不同功能分区的虚实穿插。玻璃为视觉虚面但不等于可通行空域，深凹实体仍可为实面。
3. 分别改变开口位置/面积、墙体退进、檐深、柱列位置、窗洞深度，观察真实阴影与人眼斜向视图。避免以黑色贴图伪造退进。
4. 优先使重点公共空间的内外关系可感知。对避光或安全要求高的实墙，可研究基座、墙端、接缝、局部厚度、材料与相邻开放界面的对比；不为立面强行开窗。
5. 通过穿立面的实际剖面核构造、采光、排水、遮阳及内部活动。原书图例不等于现代性能规范。

## F04 墙面分格、线条与重复单元

**来源**：图118，印刷292—295页。原书从墙、梁、柱、窗等要素的组织入手，展示横向、竖向、交织、成组开口等构图，亦强调质感对比。

**操作**：由实际楼层、柱网、客房/办公室/展厅等空间单元导出第一层构成基准；再选择横向连续、竖向连续、网格交织、成组重复或有依据的局部中断。将开口宽高、间墙宽度、竖向分段、重复周期、实体构件深度作为设计变量。不同立面可因真实朝向和功能有所差别，同时共享部分材料、模数或比例关系。
- 比较方案应保留真实内外对应；不伪造楼层及窗洞，不用均匀网格覆盖所有建筑。
- 对重复建筑，先画一个真实标准开间的平剖和立面，再研究两至数个开间的组合、转角、尽端、入口及顶部收口；对大型公共建筑则先研究一段墙面与公共空间的交界。
- 同条件观察正投影、斜向远景和近景。若建筑仅在正立面呈现节奏，进一步研究阴影与侧向深度。

## F05 材料、质感与细部层级

**来源**：图118后部（295页）及图121（296—298页，PDF305—307；前两页重点读）。图121讨论外檐装饰与建筑整体、尺度及材料的关系，给出远近观察和局部重点的例子；历史纹样仅是案例。

**操作**：分别研究整体远景的材料主次、中距离的板块与构件比例、近距离的接缝/边缘/触感。通过真实建模深度或合理材质参数比较粗细、明暗、反射和凹凸；材料改变可以是独立的艺术设计动作。优先推敲入口、转角、基座、檐口、洞口等人实际接触或重点观看的部位。装饰可参与主题表达，但其尺度、位置、节奏与整体应协调；不强制极简或装饰主义。不要照搬原书历史符号、假构造或忽略耐候、维护及施工。早期仅需构造意向，不冒充施工节点。

## G01 从场地条件推导群体轮廓

**来源**：图124，305—306页。书中学校、某公园大门、桂林七星岩月牙楼及山地住宅等图例，显示地形、朝向、人流方向和环境景观共同影响平面、体形及开放空间。

**操作**：在同一真实地界与大致容量下比较集中、分散、沿等高线、顺主要到达方向、转折及分台组织。画至少一条贯通原地形与建筑的真实剖面，判断建筑和场地的交接、主要外部空域和步行路线；利用现有土方、路径工具按需检查。平坦场地不强制造坡，坡地不盲目推平。景观建筑同时研究人如何看景与建筑如何成为场景的一部分。

## G02 群体统一的多种组织机制

**来源**：图132—136，319—323页。图132以对称取得统一；图133为轴线引导、转折；图134为向心；图135为与地形结合；图136以共同体形形成统一。图136东京日本国家体育馆组团说明不同大小的体量可借共同构成特征形成整体。

可选择以下机制，不设唯一正确答案：

| 机制 | 几何动作 | 观察与风险 |
|---|---|---|
| 对称与共同轴 | 以实体或虚空间建立主轴，协调两侧位置、体量和开口 | 看正向到达、重点和整体秩序；地块及功能不适合时允许局部非对称 |
| 轴线转折 | 按实际场地、功能分支设置相交或连续转折的轴，在交接处设真实节点 | 研究方向转换、相邻外部空间、远景及交通；不让轴线只存在分析图上 |
| 向心围合 | 多个独立体量面向共享庭院、广场、地景或活动核心 | 核心要有尺度、界面与使用；不必几何圆形或严格同心 |
| 顺应地形 | 以等高线、台地、自然边界、主要视线统一不同建筑 | 核真实标高、无障碍及工程条件 |
| 共同构成母题 | 重复可辨认的平面、截面、结构、屋盖或材料规则，允许尺度及形状变化 | 一致不等于复制；功能差异应保留；不能靠统一颜色掩盖空间关系松散 |

同一个群体可以组合多种机制，但先找主导关系。用实际总平、黑白图底、天际线及人眼视角观察。已定案项目优先改善既有机制，不为尝试新方法重画全部建筑。

## G03 外部空间的图底关系与围合程度

**来源**：图138、139，328—330页。原书讨论建筑体形与外部空间的互为图底关系、封闭与开敞等类型，并指出围合感不仅取决于围合形式，还与建筑高度、间距及疏密有关。

**操作**：
- 同时画实体建筑黑、空间白与反转图底。将有清晰形状及活动意图的院落、广场、通道等作为主动设计对象，而不只是建筑间剩余面积。也允许开放自然地景，不要求全部外部空间封闭。
- 对同一室外面积比较四边围合、三边围合、两侧夹合、单侧边界与开敞地景；在相近面积下分别改变建筑高度、相互间距及边界孔隙。
- 对同一院落可固定宽度改变边界高度，或固定建筑高度改变宽度。若采用比例参数H/W，明确H是实际边界高度、W是相应观察截面的宽度；不设置通用最优阈值。不同边界高度应分别记录。
- 用真实站点观察天空、远景、建筑界面和活动尺度；检查日照、风、视线、消防及步行可达。水体、绿化和高差可参与边界，但需考虑实际使用及维护。
- 示例：两翼水庭若像狭长通道，可比较加宽局部停留区、降低一翼、调整开口方向、端部开放或局部围合；若其原本就希望表达深远方向，则不必一律增宽。

## G04 外部空间的对比与变化

**来源**：图140，331—333页（本轮重点阅读前两页）。原书以苏州园林、北海静心斋、曲阜孔庙等例研究大小、形状、方向、开合与自然空间的对比。

**操作**：从实际前庭、主要室外节点和景观边界中选择相邻空间，以平面及真实人眼图比较大小、高低、方向、开敞与封闭的变化。自然景观可成为建筑群体之外的空间重点。对同一场地试连续均质开放空间、主次院落、半围合过渡再通向自然环境等。对功能要求高效直达的场所，保留直接路径；不为序列强行绕路。

## G05 外部空间的渗透与层次

**来源**：图141，334—339页。原书通过门洞、空廊、柱列、架空层、建筑间隙、树丛等，使多个外部空间彼此可见而又具有独立边界；实例包含传统园林框景及现代大学、医疗建筑等。

**操作**：从实际站点分别建立近景边界、中景活动、远景对象。比较直接观看、由洞口框取、透过柱廊/架空层、建筑间隙、植物过滤等关系；改变边界位置、透空范围、进深与观察方向。对景对象应真实存在或注明规划假设。分别核实际可达性、结构支承、无障碍与疏散；透明或透空不代表可以通行。并非层次越多越好，应保留清楚主次与适当留白。

## G06 外部空间的程序组织（序列）

**来源**：图142，340—345页。原书比较沿轴线纵深、主轴与横向副轴、斜向副轴和迂回循环等组织；通过故宫、武藏野美术大学、苏州留园、韶山纪念馆及1958年布鲁塞尔国际博览会等例表达连续空间关系。案例名称沿用原书，未另行核查现状。

**操作**：
- 用实际平面标入口、转换、公共核心、次级节点、景观、回程和支线。分别比较轴向、分支、循环等可行路径。
- 故宫图例启发：规则轴向也能通过门、院、建筑体量和空间收放形成连续变化；不要求现代建筑复刻礼制或尺度。
- 留园图例启发：循环路径可以多次接触同一中心，从不同方向重新感知；不必只有一个高潮。
- 布鲁塞尔博览会图例启发：大型群体可以设置多个清晰中心及不同入口，形成选择性序列。研究主节点的可辨识性及彼此联系，同时保留自由路径。
- 用实际相机站点、贯通平剖、连续人眼图观察空间。外部路线要包含日常直达、可选择漫游和必要服务/疏散条件；不以预设戏剧性替代使用需求。

## H. 设计诊断与调用示例

| 具体问题 | 建议先试的操作 |
|---|---|
| 大面积墙面平庸 | F03虚实/凹凸、F04真实分格、F05质感；避免直接增加假窗 |
| 建筑只在鸟瞰图好看 | F01动态均衡、F02剪影，从道路及步行真实视点验证 |
| 多个体量各自为政 | G02选择主导统一关系，联用C01/C02体量操作 |
| 室外广场空旷或院落逼仄 | G03边界间距与高度、G04相邻空间对比 |
| 景观有价值却难以感知 | G05框景/层次、G06主线与支线、G01场地关系 |
| 酒店标准层立面机械重复 | F04基于真实单元的重复与变奏，F05转角和入口细部 |

只选有价值的操作，完成真实设计改动并观察前后差异。建筑设计的审美效果仍由实际成果与设计者评价决定。此次研读未通过新项目验证上述方法。

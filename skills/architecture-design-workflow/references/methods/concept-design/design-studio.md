# 建筑创作工作台：从空间原型到可评图的建筑

本方法用于概念与方案阶段，目标是改善建筑本身的空间、构成、光线、材料与场地关系。它是建筑设计方法，不是规范、自动评分器或固定风格模板。项目硬约束、用户授权及已确认方案仍由主入口控制。需要技术验证时调用既有工具，不另建测试框架。

## 1. 开始创作：先找值得做的空间

在详细房间划分之前，先从场地和人的活动中找出一至数个具有建筑价值的关系。例如：入口与远景之间的距离；多个使用群体围绕同一公共空间；安静房间与活跃公共路径之间的界面；自然光从顶层进入较深空间；建筑实体与连续地形之间的关系。

不必将所有审美目标证明为功能矛盾。比例、材料、结构表达、场所精神可以是独立的设计目标，但须落实为可观察的空间。先用一句话表述希望人在什么位置看见、感受到或做什么，再决定空间几何。

将设计分为三个尺度同步推演：

- 整体：建筑与场地之间的关系、主要轮廓和主次实体。
- 空间：核心空间、相邻空间、过渡与路径。
- 构件：墙、柱、梁、屋顶、门窗、台阶和材料界面。

不要从一种屋顶、斜墙或装饰开始然后为它寻找理由；也不要默认只能从房间矩形拼接开始。允许平面优先、剖面优先、核心空间优先、结构原型优先或场地优先。

## 2. 最小设计推演循环

根据当前问题进一步选读教材转译方法：[建筑空间设计](spatial-composition-theory.md)处理形式规律与单/多空间，[园林空间设计](garden-space.md)处理动态视觉与室外空间，[草图与建筑表现](sketch-and-representation.md)处理低成本视觉推演，[类型设计资料](building-type-study.md)处理具体活动与功能原型。以上为原创方法转译，非教材全文；不要求全部加载。

按当前问题选读[空间与构成原型](spatial-patterns.md)和[案例转译](precedent-transfer.md)。以下工作是设计活动本身，不是要求另写报告。

1. 画出场地约束与粗略功能面积带，估算楼层容量、进深和必要交通。
2. 选择具有区别的空间组织机制，给每个候选一个清晰的主导关系。用实际平面轮廓、关键剖面与简化模型表达。
3. 在每个候选中找最有价值的核心空间，先推敲它的宽、高、深、开口、主要视线和活动，再考虑相邻房间的接入。
4. 通过同一空间的几种比例、实体/开口关系或标高方案做小模型对照，实际打开渲染图或草图。改变空间关系而非只换色。
5. 将有效构成扩展到全楼，协调功能容量、结构与交通。若整体退化，回到核心关系修改，不能只在退化结果外面增加屋面或立面装饰。
6. 对候选进行公平评图，保留少数真正值得深化的方向交用户选择。已选定概念则集中修正实际问题，不强制重新发散。

必要时在草图上使用简化比例和坐标，以当前项目的实际尺寸替换；不要求先完成全套墙柱和家具才能进行审美研究。真实模型阶段再进行几何与规范校核。

## 3. 建筑构成的七个可操作变量

| 变量 | 应当怎样修改 | 观察证据与反例 |
|---|---|---|
| 主从 | 明确核心公共空间或主体量；降低次要体量、收拢次要开口、控制连接件 | 从入口和远景观察是否有明确重点；若每栋体块均突出，整体失去秩序 |
| 比例 | 对同一空间改变净高/宽度、开口/墙面、实体/虚空间及屋檐厚度 | 比较正投影、剖面、人眼视图；不设所谓万能美学比例 |
| 节奏 | 建立重复的结构跨、柱列或空间单元；在入口、转折、核心空间有根据地中断 | 节奏应在平面、剖面和行进中可感知；无限重复会产生机械感 |
| 虚实 | 先设计可使用的院落、凹口、外廊、平台，再围合实体 | 虚空间有明确边界、出入口、停留与采光；残余空地不是庭院 |
| 连续与断裂 | 用统一基座、屋面、结构线或地形连接，同时允许必要的错位与开敞 | 整体轮廓与关键剖面均可读；不能靠将所有体量包进一个装饰外壳掩盖矛盾 |
| 光线 | 决定受光面与遮挡面，设计深檐、顶光、高侧窗、反射面和阴影边界 | 开口应产生预期空间效果；高亮窗洞不等于深部采光有效 |
| 材料与建造 | 研究材料厚度、连接方式、接缝、转角、真实支承与触感；限定主要语言 | 无材质白模也应有构成质量；材质渲染不能代替真实几何和建造逻辑 |

以上是推敲方向，不要求每个项目都执行七类操作。一个极简建筑可以靠少数关系获得很高的形式品质；复杂建筑也需要可理解的统合规则。

## 4. 按人的连续体验设计

先画一条实际使用路径：起点、入口、核心空间、功能分岔、停留、返回或离开。标记人站在哪、看向哪里、是否需要转向、是否知道下一步怎么走。

在关键节点做真实人眼视图与剖面：正常入口高度下观察压缩与释放；从核心空间看出入口和垂直交通；从外廊看庭院或景观；从二层看首层与外部；从回程看是否容易辨认方向。

用视线而非仅用交通箭头判断体验：

- 门口是否能看见核心空间的一部分？是否需要故意延后揭示景观？
- 转折处是否有可识别的方向提示或空间焦点？
- 路径宽度变化是否对应活动变化？停留空间是否阻断通过？
- 核心空间是否可从多个位置重新识别？
- 静态轴线是否与动态体验相互支持？轴线可以偏移、折转或被打断。

不要每次强制采用暗廊—亮庭—观景的叙事。学校、办公、住宅与纪念建筑的活动节奏不同；直接、明亮、短距离的路径也可以是优秀设计。

## 5. 核心空间专项推敲

外部形象、立面、建筑群及场地空域问题，按需调用[立面、群体构成与外部空间操作](facade-and-ensemble.md)，通过真实剪影、墙面构成、近远视点、图底、围合截面及连续空间比较改动。


需要具体改图时优先查[空间与体形操作手册](spatial-operations.md)。从局部柱列、夹层、顶地墙或相邻空间关系中选择与当前问题相关的实际几何操作，直接比较草模；整体形体问题则研究加法、减法、主从和比例层级。无需把全部手册当作必做流程。

选择真正决定项目品质的空间，不做全部房间的机械实验。

### 入口

用两张图同时表达从道路接近与从门内回望；尝试前庭、深檐、门槛、柱列、墙端、地形等不同空间关系。入口不是单纯放大门洞；研究等候、集散、遮雨、无障碍和使用者能否识别其位置。

### 大厅与公共节点

先决定大厅承担分配、共享活动、展示、观景或方向识别中的哪些任务。用平剖安排不同方向的视线和竖向交通，明确停留区与通过区。通过局部高度、开口或结构建立重点；不强求通高、雕塑、纪念性或中庭。

### 院落与室外空间

将院落当作需要设计的房间：明确天空边界、围合的高度与宽度、地面、界面、活动、出入口、光影。比较完全围合、向外景开放、半室外包边、分级院落。必要时放置简化树木和座位判断尺度；不默认所有院落都应该有水或绿化。

### 主要使用空间

从实际活动出发研究视线、净高、支承、家具或展陈、光线与边界。一个有独特空间原型的房间应能适应其使用方式；不要为了构成强行统一不同房间的净高，也不要让独特形式产生大量无法使用的边角。

### 屋面与剖面

决定屋面是覆盖、导光、形成公共地景、表达结构或围合高空间中的何种角色。同步画屋面结构意向和空间剖面。比较整片屋盖与多个同族屋盖，判断其尺度是否回应建筑内部；不把随机折面当作设计进步。

## 6. 从构成到真实模型

对选中的主导关系定义少量可修改的设计参数：主体/虚空间范围、控制标高、结构跨、关键开口、路径和屋盖控制线。内部房间可独立适配，不让每个房间边界自动决定最终外壳。

早期验证采用能揭示问题的最低必要精度：同尺度总平、穿核心空间的剖面、体量白模、重要节点人眼图。后续模型应逐步加入真实厚度、支承、楼板、门洞、必要家具、地形与环境。

如果技术约束破坏了主要构成，比较以下修正：改变房间组合；重组交通；调整体量比例；改变楼层范围或剖面；在确有依据时改主导关系。不要默默保留全部外部几何并把所有矛盾压入内部，也不要默认牺牲审美目标。

## 7. 评图方法：给出具体诊断和修改

评图分两条线：

- 技术成立性：功能、面积、连通、结构、规范及其他项目约束。由项目实际证据判定。
- 设计品质：构成、空间、光线、材料、场地、活动与主题。由实际图像、使用推演、比较及用户审美反馈判断。

同一设计问题采用同尺度、同机位、同光照对照；至少观察能够暴露弱点的视角，不只挑最漂亮的一张图。白模用于看几何，真实材质用于看感受，两者不能相互替代。

有效批评应包含位置、现象、原因假设和几何修改。例如：

- 「庭院在入口视角只像通道」→ 查看剖面高宽关系、边界开口、末端和停留节点 → 比较局部扩宽与侧翼围合两种模型 → 结合实际路径与面积选择。
- 「入口过于平淡」→ 查看接近方向和墙、檐、柱、开口的主次 → 比较深门槛、前庭转向或门厅可见性 → 不用夸张悬挑或更漂亮材质作为唯一修复。
- 「屋顶太碎」→ 比较总平的整体轮廓、结构跨和各空间高度 → 尝试同族单元或统一屋盖，同时验证层高、排水与光线。

保留旧版本作为对照。评图结论写在实际图旁；不需要通过长报告或数字评分证明建筑优秀。设计者可以提出偏好，用户保留关键审美选择。新版本不一定更优秀；如果重复修改没有明显改善，应回看有价值的旧方案或请用户选择。

## 8. 如何判断本方法是否有效

在新项目中用相同任务书、相近预算和表现条件，比较原工作流与采用本方法的真实平剖面和模型。评价独立的核心空间品质、整体构成、设计决策清晰度、功能可行性和用户偏好。单元测试只用于技术工具；本方法的有效性仍需设计者评图和真实项目验证。不要声称读完本文即具备大师的设计能力。

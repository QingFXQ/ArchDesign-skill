# 空间原型与建筑构成：可执行的设计操作库

本库是供建筑设计者选择、组合、修改的原创抽象方法，不是建筑类型目录或自动套用模板。示意均为拓扑/剖面关系，不代表真实案例图纸或固定尺寸。尺寸取自项目容量、结构、气候和人的活动；引用案例见[案例转译](precedent-transfer.md)。与[建筑创作工作台](design-studio.md)结合使用。

## 选用方法

已有空间原型但空间品质不足时，按需查[空间与体形操作手册](spatial-operations.md)，以具体构件、界面、连接与体量关系推敲原型，不必每次更换整个空间组织机制。

先问主要活动、场地和空间冲突，再选主导原型与必要辅助原型。一个方案通常需要一条可以清楚表达的整体构成规则；不以使用原型数量为优点。先把公共空间、建筑实体、路径和地形的关系画成实际比例的简图，然后分别建立平面和剖面原型。

符号：■ 实体功能；□ 核心空/共享空间；· 路径；~ 水或外部景观；↑ 高差/垂直联系。示意图只表达关系。

## P01 中心与外围：可识别的空间核心

```
      ■ ■ ■
      ■ □ ■
 入口 · □ · ■
      ■ ■ ■
```

**问题**：多类活动需共享核心，首次到达应能迅速理解方向。

**操作**：先定义中心的真实形状、宽度、高度、开口与主要活动；使不同功能直接或通过门槛与核心相接；按声、光、私密性分层围合。可以采用单层中心或跨层中心，并将垂直交通纳入空间秩序。

**推演**：比较居中与偏心、单层与通高、四边围合与向场地开口。保持主要功能容量，观察入口视线与到各功能的路径。若中央空间只剩楼梯和交通，缩小中心或把实际公共活动移入。

**剖面/验证**：穿入口—核心—外围，画楼层、结构、光源和视线。适合图书馆、公共文化设施、社区中心、酒店公共区；噪声敏感区域需缓冲，通高可能消耗面积及增加烟控、空调负担。参考 Exeter 图书馆。

## P02 主轴、支轴与序列：控制移动和发现

```
  ■     ■      ■
入口 ··· □ ··· □ ··· 远景
  ■       ■      ■
```

**问题**：狭长场地、多章节活动、到达与远景有方向性。

**操作**：先定义起点和主要空间节点；选择直轴、折轴、偏轴或环行支线。以节点而非同质走廊组织空间；用局部扩大、缩小、转向、门槛和光线变化建立节奏。需要自由选择时保留捷径与回路。

**推演**：比较直达景观与延后揭示；比较连续长廊与多个真实停留节点；每个节点通过人眼视图验证视线焦点。若轴线两侧都是同样的门洞与墙段，删减无意义长度或改变路径与空间的关系。

**剖面/验证**：连续剖面与路径序列，标实际出入口、无障碍和返回路径。适用于展馆、校园、文化街区等；长路径可能增加面积与行走负担，叙事不可强迫所有使用者绕行。参考 Louisiana、地中美术馆。

## P03 院落围合：以虚空间组织建筑

```
  ■■■■■
  ■ □ ■
  ■ □ ··· 外景
  ■■■■■
```

**问题**：需要内外联系、安静共享空间、方向识别或自然采光。

**操作**：先确定院落的使用方式、天空范围和主要界面，再围合体量；决定哪一边开敞、哪一边实体、哪一边有廊。通过分级院落、半围合和标高差建立主次。

**推演**：固定建筑面积，比较紧凑深院、宽敞浅院、开口向外景的院落。检查院落宽高关系、天空可见范围、各时段阴影、界面活动和停留。若只有交通从旁通过，研究让功能直接使用庭院或将院落缩减为真正的光庭。

**剖面/验证**：沿庭院宽度画两侧功能、窗、廊、坐人位置、建筑高度。无需固定高宽比。住宅、学校、办公、医院和公共建筑均可使用，需按气候、噪声、私密、通风、消防及维护判断适用性。参考 Säynätsalo 市政厅。

## P04 两翼对望与跨越：让空隙成为组织核心

```
  ■■■■  ····  ■
  ~~~~~~~~~~~~~
  ■■■■  ····  ■
```

**问题**：场地包含重要景观、共享庭院、水体或不可直接穿越的自然边界；两组功能需可见、可分离又可连接。

**操作**：先画中间的空域，再定两翼朝向、距离、体量主次和连接位置。可采用单端连接、两端回游、跨桥、不同层连接或局部围合。用透明公共界面与实体功能界面形成对比。

**推演**：比较平行与略微偏转、连续界面与分节界面、中央与端部跨越。研究走桥时视线如何由近景转为远景；不要将水面当作装饰。水体应明确水文与安全边界；无需水时也可用下沉院或绿地。

**剖面/验证**：穿越两翼与空域，检查两岸/两侧相互观看、通达、疏散、日照和结构。适用于文化建筑、校园共享设施和景观公共建筑；需警惕重复走廊、维护成本和服务路线绕远。参考沃斯堡、萨尔克研究所；不能直接套用其水位和具体尺寸。

## P05 空间集群与渗透网络：独立单元、共享空间

```
  ■■   □   ■
     ·····
  ■ · □ · ■■
     ·····
  □   ■    □
```

**问题**：房间独立性强、多路线使用、功能可独立开放。

**操作**：定义若干不同尺度的单元和共享空间，建立通行网络而非先画单一长廊。将服务、安静和开放界面有意识地区分；明确可以关闭的门和控制点。

**推演**：比较紧凑网络、分组网络、多个共享节点；尽量保持结构模数并改变单元位置与路径。若空隙成为无法利用的碎片，把共享空间当作需要独立预算的房间重新组织。

**剖面/验证**：从入口到任意主要功能追踪实际可达路线，核开闭条件、方向识别、服务和光照。适用于展厅、学校、社区中心及共享办公；无边界的开放性可能损害安静、管理、消防和方向感。参考金泽21世纪美术馆。

## P06 重复原型与变奏：让结构、屋盖和空间共享语言

```
   /\   /\   /\      /\
  |■■| |■■| |□□|    |■■|
  +--+ +--+ +--+    +--+
```

**问题**：多组类似活动、需要统一构成，但空间尺度与光线需求有差别。

**操作**：先设计一个真正能容纳活动的结构/空间单元，明确净跨、净高、顶面、采光与支承；通过重复、合并、间隔、旋转、尺度变化形成整体。少量特殊单元对应真正重要的空间。

**推演**：先独立建单元模型，再比较若干组合；研究重复频率、入口识别和缺口形成的庭院。避免每个房间配一个独立屋顶导致碎片化；也避免强制所有功能等高等跨。

**剖面/验证**：单元剖面与整体屋盖关系图，核支承、光线、排水、适配和检修。适合教学、厂房、市场、展馆、体育设施；重复不必意味着拱、斜顶或某种固定材料。参考金贝尔、御窑博物馆。

## P07 实体切削与门槛：通过负空间建立轮廓

```
  ■■■■■■■
  ■■ □ ■■
  ■  ·  ■
  ■■■  ■■
```

**问题**：需要明确建筑整体性、重要入口、受保护空间或具有强烈实体感的构成。

**操作**：先定义可容纳功能的整体边界；以入口、庭院、光庭、穿越或退台切出具有真实使用意义的负空间。切削深度、方向和尺度受活动、结构、排水和光线决定；保留主体的完整性。

**推演**：同一个主体比较少量大的负空间和多个小负空间；观察主要轮廓、入口远近、洞口深度与内部净面积。避免随机切角、无意义的斜墙和不能使用的三角形房间。

**剖面/验证**：切穿负空间，标出上下楼层、结构和真实出入。适用于紧凑公共建筑、实体感较强的场所；过深进深与封闭外墙需验证采光、通风、疏散和结构。参考地中美术馆；其地下艺术展览的条件并非一般项目条件。

## P08 剖面分层、错层与台地：用高度组织体验

```
              □■■
        □■■  ↑
 入口 ···↑
     ■■□
```

**问题**：高差、不同层高功能、跨层视线、分级公共性或地形限制。

**操作**：先画沿主要路径的连续剖面；设置地面、关键平台、核心空间和上层联系。以台阶、坡道、楼梯、坡地或抬升空间解决实际高度关系。视需要将高大空间旁边布置低尺度支持空间。

**推演**：比较顺坡分台、下沉、抬升、统一标高等方案；核实际路径长度、回路、无障碍、独立服务与结构。每一处高差需给使用和感知带来可观察的收益。

**剖面/验证**：场地—建筑连续纵剖面和另一条横剖，核排水、防水、土方、净高、平台与交通。适合坡地、文化建筑、校园及公共空间；不得用只画箭头的坡道掩盖实际长度。参考 Säynätsalo 市政厅、丹麦海事博物馆。

## P09 连续覆盖与地景：让屋顶/地面成为整体秩序

```
   ___/\____/\___  屋盖/地形
   ■ □ ■ □ ■ ■
  ---------------- 场地
```

**问题**：多个功能需要统一形象、室内外连续、遮蔽或适应地形。

**操作**：区分独立屋盖、连续屋盖、可步行屋面、覆土地形；选择与结构和功能相符的覆盖逻辑。设置光缝、院落或局部露天区域，使覆盖体系与内部空间发生明确关系。

**推演**：比较单片连续覆盖与重复原型、平行与折转、不同局部高度。若屋顶下空间被挤压或留下大量不可用体积，回到剖面协调而非只调外形。覆土需要单独处理荷载、排水、防水和维护。

**剖面/验证**：连续屋盖剖面、屋面投影、行人及远景视角；验证采光、结构、排水和实际使用。适用于大型公共建筑、景观设施、交通空间；没有公共屋面需求时无需为了形式增加步行路径。参考 Louisiana 的嵌入式扩建、御窑博物馆的重复空间原型。

## P10 光作为空间原型：用截面组织自然光

```
      ↓光
   ---  ---
  |   ↘ ↙  |
  |  受光面 |
  |_________|
```

**问题**：深进深、展陈、阅读、室内活动或特殊光线气氛。

**操作**：先确定目标受光面、观看位置与需要遮挡的直射光；分别尝试侧光、高侧光、庭院光、顶光、间接反射或透光界面。改变剖面而非只扩大窗洞，研究光源、遮挡、反射面和结构的位置。

**推演**：保持照明参数和空间尺度，比较开口位置、反射板角度、光井深度等。观察近处与深处、对比眩光和光线方向，不从一张漂亮渲染推导照度合规。

**剖面/验证**：用实际截面、受光路径和同机位真实模型对照。需要精确结论时采用专业照明分析。适合图书馆、展览、教学及公共大厅；保护光敏物品、眩光、热工、维护及人工照明需求可能限制自然光。参考金贝尔、布雷根茨美术馆。

## 原型组合示例（抽象设计，不是建成案例）

| 项目机会 | 组合 | 优先看什么 | 失败时如何修正 |
|---|---|---|---|
| 有公共景观的文化设施 | P04 对望 + P02 序列 + P10 光 | 路径能否持续感知景观，独立功能能否运营 | 减少重复交通、调整翼间距和过桥点 |
| 小型学校或幼儿园 | P05 集群 + P03 院落 | 室内外活动、教师视线、不同年龄共享 | 按年龄组调整院落和门禁，减少不可监管死角 |
| 图书馆 | P01 核心 + P10 光 | 到达方向、安静阅读、书库与活动分界 | 将喧闹活动分离，收缩不必要的挑空 |
| 酒店公共区 | P01 核心 + P02 序列 | 入住、宴会、住宿与服务的分流 | 将客房标准层与公共体量协调，压缩重复大厅 |
| 坡地社区中心 | P08 台地 + P03 院落 | 城市不同标高的入口、共享空间和无障碍 | 改台地位置和垂直交通，重新检查连续路线 |

组合不意味着必须同时实施所有特征。先确定主导原型，再取少量辅助操作，用真实模型验证。

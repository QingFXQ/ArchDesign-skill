# 建筑空间设计：理论转译与构成推敲

来源：彭一刚《建筑空间组合论》（第二版，中国建筑工业出版社，1998）。本文件是为 Agent 建筑创作编写的原创实践方法，不是原书替代品。页码使用本次阅读的扫描 PDF 页序；正文印刷页码通常比 PDF 页序小9。已重点研读绪论、功能与空间、空间与结构及第4—7章正文，抽查对应附图；第8章已在第二轮完整研读，另抽查后半部结构、形式美、内部空间、体量及群体图版；大量图版仍未逐项精读。下列操作与实验是依据理论推导的工作方法，未经过跨项目实测。

## 1. 首先修正创作立场

原书第1章从功能、精神审美、物质技术及发展关系讨论形式（PDF 10–19）；第2章从单空间与多空间讨论功能对形式的规定性（21–28）；第3章研究不同结构体系对空间及外形的影响（29–39）。

设计任务同时包含实用、构造、审美与场所表达。审美与精神目标允许独立发起设计实验；其成立依据可以是空间秩序、尺度、感知或材料表达。没有必要为每条斜线、每个比例决定编造功能矛盾。艺术目标必须落实到真实空间；技术风险必须如实检查。两条线可相互修正，不能相互抵销。

允许采用不同创作入口：空间原型、结构体系、场地构成、功能组合、形式构成。先控制容量与硬边界，具体房间和外围几何随后双向适配。

## 2. 在一张草图上同时明确三类关系

- 功能：活动的空间容量、形状、环境、相互联系和分隔。单空间满足活动不意味着整体功能成立。
- 结构：真实支承位置、跨度、楼层与屋顶高度；早期是可建造意向，不冒充结构计算。
- 形式：整体构成规律、虚实和重点、人在不同距离与方向所能感知的空间。

例如一个共享大厅可以是同一框架中的多个空间单元、独立大跨核心、厚墙之间的连续空间。不要先确定一个雕塑屋顶再随意加柱，也不要因采用框架就让所有开间、屋顶及房间相同。

原书第2章后半（PDF 26–28）区分交通联系相对独立的单元、使用空间相互穿套、放射联系、使用与交通空间综合组织及大空间与周边小空间等关系。用这些关系扩展当前原型库；一个复杂项目可以组合若干组织，不须把所有功能强塞进一种拓扑。详见[空间原型](spatial-patterns.md)。

## 3. 形式构成操作（第4章，PDF 40–51，附图如196、198、204、210、215、220）

| 操作 | 实际改动 | 比较方法 | 容易失败之处 |
|---|---|---|---|
| 几何统一 | 选择可识别的控制方向、共同几何族或整体基准；把少数异形留给重要位置 | 统一相机的轮廓图、总平与屋顶图 | 用外壳遮蔽内部杂乱；误认为仅正方形/圆形才美 |
| 主从与重点 | 改变主要空间的尺度、位置、围合、开口和高度，次要体量相应让位 | 从远景、入口、核心活动点判断重点是否一致 | 每个展馆、屋顶、入口都强调，彼此争夺 |
| 均衡与稳定 | 比较对称与非对称构图；调节体量、阴影、位置和基座，研究视觉重心 | 正立面、斜向与场地主要到达方向的剪影 | 机械镜像，或在无结构依据时制造悬浮 |
| 对比与微差 | 固定一个共同基准，改变少数宽高、厚薄、方向、明暗或虚实变量 | 同条件两至数个模型，明确变化引发的感受 | 同时改动太多变量，或以极端差异替代协调 |
| 韵律与节奏 | 重复一个真实空间或结构单位，使用间隔、组合、渐变、停顿和特殊节点 | 立面、连续剖面、沿路径视图 | 房间级碎屋顶；重复无停顿；开口节奏与室内无关 |
| 比例与尺度 | 同时研究整体与部分的相对比例，以及绝对尺寸与人的活动尺度 | 带实际家具、结构及人体的平剖、人眼透视 | 盲套黄金分割；靠广角相机放大空间；巨大构件消解人的尺度 |

不要把视觉均衡简化为可计算的质量中心。图形关系仅作为构成推敲的工具，最终仍需读图。比例研究无须给定通用最美数值；先由使用、结构及场所条件得出合理区间，再比较可行变体。

### 三层比例控制

1. 整体与场地：建筑高度、长度、留白、主要开放空间与周边参照物之间的关系。
2. 空间与整体：核心空间在楼层、屋盖和群体中的地位；次要空间有无足够但不过度的尺度。
3. 人与构件：门槛、柱、梁、栏杆、墙厚、材料分缝与人体、家具、活动和观看距离的关系。

在设计草图上给出重要实际尺寸。用于相对比较的示意模型应清楚区分未确认尺寸。

## 4. 先设计单一空间（第5章第一节，PDF 52–58）

针对具体空间或体形问题，可直接选用[空间与体形操作手册](spatial-operations.md)：其中按原书图解索引提供柱列、夹层、顶地墙界面、相邻空间对比、过渡与引导，以及加减法组合、比例和尺度的实际建模动作。第三轮研读补充了这些选定图版，详见该手册的研读范围。

每个决定建筑品质的空间，按其活动选择若干关键变量，先用粗平面、剖面和人眼草图推敲：

- 体量与尺度：面积相同但净高不同，感受与用途可能完全不同。把高度、宽度、长度与使用者尺度同时显示。
- 形状与比例：空间长宽关系及其方向性影响注意力、活动布置与视线。比较紧凑、延展、具有方向性的平面，不能仅靠房间面积校验。
- 封闭与开敞：围合界面及开口的位置和尺度同时决定安全、亲密、开阔、内向或外向体验。玻璃的透视关系与实际通行是两件事。
- 空间分隔：通过柱列、局部墙、家具、台阶、顶面或地面变化形成不同程度的分隔；考虑声、光、视线及使用边界。避免为了局部装饰切碎完整空间。
- 界面：顶面、地面和墙面作为构成整体研究，开口、结构、材料和高度变化有共同的比例关系。
- 色彩与质感：根据光线、距离、接触及空间角色决定材料的表达；不要让全部界面在同一饱和度、纹理密度或强对比上竞争。

### 一个具体推演例（原创，非书中范例）

假设公共大厅净面积约400平方米。先从当前功能与结构确定可行高度。试三个等面积平面：20×20、16×25、约14×28.6米。分别研究入口、主楼梯、观景口和支持空间如何落位。用可建造的粗模型比较同一高度下的方向性；选出候选后再比较不同净高与局部通高。观察真正使用的大厅与沿边通行是否相互支持。数字只是实验起点，不是推荐大厅指标。实验不要求为每个版本绘制完整全楼。

## 5. 再设计多空间之间的关系（第5章第二节，PDF 58–64）

这一层与单间空间品质不同；功能连接通过不代表空间组合优秀。

| 组合问题 | 建筑操作 | 观察证据 |
|---|---|---|
| 对比与变化 | 相邻或连续空间改变大小、高低、开合、形状、明暗；控制转换方向 | 同一真实行进路径上前后两个视图与贯通剖面 |
| 重复与再现 | 复用同一空间单元或构成母题，通过停顿与变奏强化记忆 | 屋面、连续截面、序列的重复与不同 |
| 衔接与过渡 | 在差异明显的空间之间调整门槛、前室、廊、平台、转角或半室外空间 | 穿过两空间和过渡处的剖面及人眼视图 |
| 渗透与层次 | 通过开口、柱列、错层、透明/半透明界面或内外连接，让空间可相互感知 | 从两侧及不同标高观察；另查通行与功能边界 |
| 引导与暗示 | 利用开口、结构方向、地面连续性、顶部高度与光线提示前方目标 | 从真正分岔及入口观察能否识别前进方向 |
| 空间序列 | 综合起点、展开、重点、停留、回返及不同路线的体验 | 带节点编号的真实路径、平剖面及连续透视 |

按使用性质选择序列。学校日常路线可短捷明亮，纪念建筑可有更强的对比与节奏；不要一律设置低暗入口、巨大高潮与漫长绕行。

### 组合推演方法

先建立两到几个关键空间的粗模型，不立即铺满房间。用实际门槛和结构界面连接，调整相邻空间的大小、距离、方向、标高和视线。每次修改后从移动者位置观察一次，保留能改变空间关系的设计。再把组合扩展到全楼。若扩展时核心空间退化，回到连接关系与功能分组修改。

## 6. 外部体形与立面（第6章，PDF 65–77）

第四轮图版研究进一步沉淀为[立面、群体构成与外部空间操作](facade-and-ensemble.md)，按具体问题选择动态均衡、虚实凹凸、墙面分格、群体统一及外部空间围合等设计操作。


原书将外部体形与内部空间、建筑个性、体量组合及立面处理联系起来。外部构成既受内部空间限制，也能在整体意图下进行相对独立的艺术组织。

- 先画出主体、次体、基座、顶部、连接与关键虚空的关系，再细分立面。允许若干体量通过重叠、邻接、嵌入、联系体或共同方向形成整体。
- 研究外壳与真实楼层、开口、结构、室内高度的对应。连续屋面若覆盖多个房间，先决定其空间或结构规则，不由单间多边形拼成。
- 立面设计同时比较实墙和开口的层级、水平/竖向线条、尺度与深度、转角、入口、顶部与地面收头。阴影由真实厚度和位置产生。
- 立面无需每一处同样丰富；后勤与公共界面可以不同，但长墙的比例、构件节奏及与道路的关系仍须研究。
- 用主要到达方向、人眼远近及湖岸/街道等外部视角评估；正立面和鸟瞰都不能代替步行感知。

## 7. 群体和外部空间（第7章，PDF 78–91）

从环境、地形、群体组合、统一及外部空间处理研究建筑之间的关系。将开放空间作为与实体同等重要的设计对象，先明确它的使用、界面、高差、方向、边界与周边城市/自然环境，再研究实体之间的距离与组合。

群体可由对称轴线、共同构成方向、连续公共空间、顺应地形或相同结构/材料母题统合。允许多个不同尺度与角色的建筑并存；不要通过统一色彩掩盖缺乏关系的单体组合。通过实际总平与纵横剖判断群体轮廓、环境响应、入口及服务流线。进一步使用[园林空间设计](garden-space.md)研究动态景观。

## 8. 接入实际创作

当任务是“更好看、更有设计感”时，先定位到整体、单空间、空间组合、立面、群体或表现的具体问题。为最有价值的关系做少量真实草图对照，选定有效几何动作再写回当前方案。不要增设评分表和额外技术测试来代替这一过程。

参考[草图与建筑表现](sketch-and-representation.md)选择观察方式。只保留对实际决策有用的图面。技术约束仍采用项目已有模块处理；完成状态由实际方案、用户反馈和任务书决定。

## 9. 多种审美语言与创作自由（第8章）

续读范围：印刷83—100页，PDF92—109，完整正文。该章为1998年第二版增补的历史语境研究，讨论古典构图、现代技术美学及20世纪后期西方建筑审美变异，不代表今日潮流排序。作者结尾同时讨论新倾向的启发、局限及立足本国实际的必要性。以下为原创设计实验建议，并非原书的风格分类或评价尺度。

上一节统一、主从、均衡、节奏等规律是有用的构成工具，但不设定唯一美学标准。具体项目可以从以下不同语言出发，各自发展一致的空间和建造逻辑。

| 创作语言 | 试着改变的真实设计关系 | 应观察及避免 |
|---|---|---|
| 经典几何秩序 | 基本几何族、轴线、实体和虚空间、体量主从 | 统一和变化能否同时存在；避免僵硬对称 |
| 技术表达 | 结构跨、连接、支承、轻重界面、采光与围护 | 构造是否塑造真实空间；不以虚构外露构件冒充受力 |
| 多义与复杂性 | 两套可解释的空间关系叠合、正反入口、开放与封闭界面 | 不同使用者能否发现不同体验；可理解性不必等于几何单一 |
| 个性及非常规形式 | 非对称、比例反常、局部突变、选择性打破重复 | 变化是否具有可识别的效果；避免每个构件都追求奇异 |
| 历史文化转译 | 从历史空间、结构、比例、材料、构造及活动中提取母题，并改变尺度或组合 | 能否成为新建筑自身的语言；避免符号拼贴及无依据历史叙事 |
| 地方性 | 真实气候、地形、地方材料、建造方式、公共生活与场所记忆 | 形式是否回应具体环境；不强制仿古，不把地方性等同于装饰 |
| 断裂与多重几何秩序 | 真实的方向交接、错动、分离、穿插或切削；比较保留连续性与主动断开的方案 | 碰撞是否产生有意义的空间、视线和体验；避免任意扭曲和假结构 |
| 自然与生态 | 以地形、光、风、植被、开放空间与资源利用生成空间和形态 | 生态效果需要另行验证；绿色视觉不等于环境性能 |

以上语言不必一次全部研究，不是固定选项表。项目概念仍开放时，可从真正有价值的两三种语言构造不同假设；已经确定方向时，仅选择对其有帮助的操作。对同一设计条件，允许比较安静、克制的方案与富有戏剧性的方案。用户审美反馈保留具体语境，不将一次偏好推广为普遍法则。

## 10. 附图研读与构成实验（第二轮）

以下图号与PDF页序直接来自本次查看的原书图版。大批其他图版尚未逐项精读；不要将这些摘取视为全书图解的完整索引。图面均在本次上传的原书中查阅，仓库仅保存页码与原创方法。

### A. 基本几何、主从与比例

- 图64（PDF196）：由简单几何取得统一；图65（198）：用大小、位置与重复研究主体。图68（204）、图72（210）、图73（215）、图75（220）分别提供对称均衡、对比、韵律与比例的图解。
- **实验**：用同一个面积预算分别做三种构成：统一的几何母题、主次体量形成重点、重复原型中一个关键变化。先只看正投影剪影与无装饰白模，再检查内部核心空间；若形式区别只来自相机或材质，重新做几何。
- 对比例实验，既比较相似外形在不同绝对尺度下的差异，也比较同一绝对尺度中各部分比例。不能由图75推导任何固定的最美比例。

### B. 结构原型与空间界面

- PDF154、166、178、190抽查不同传统及大跨度结构图版：屋顶外形、支承及室内空间同时出现。
- 图86（PDF238）用平剖面和人眼图比较不同空间围合、开口及界面。PDF244、250、256、262、268显示顶部、空间衔接、渗透、引导和序列等例。
- **实验**：对于同一空间容量先研究两种可行的结构截面或支承关系，再研究屋盖、受光面、边界与人体感受。形体原型应有真实支承意向，但概念阶段不冒充工程计算。用平面、横剖和室内视图三者对应，判断是否真正创造了空间。

### C. 体量拆解与有机结合

- 图107（印刷271页、PDF280）以北京天文馆为例：用平面、轴线和分解轴测揭示门厅、天象厅、展览厅、电影厅、陈列廊的相互关系；组合涉及几何体、主次和连接。
- **实验**：先独立设计各关键功能的体量原型（例如圆形或多边形核心、矩形翼、共享廊），再画分解轴测和组合平面。对照相接、嵌入、由共享空间联系三种真实连接；明确体量间轴线、楼层标高和接缝。调整大小与主从，避免为追求有机结合而合并成无区别的巨型外壳。
- 图110（PDF286）涉及稳定感；PDF292、298、304可用于观察轮廓、入口及外部构件如何形成建筑特征。不要从建筑照片独断内部结构。

### D. 群体与外部空间

- 图122（PDF310）用不同群体案例说明单体之外的组合意义；PDF316、322为场地及群体布置的例图；图132（328）讨论通过对称取得群体统一；图140（340）对比外部空间的变化。
- **实验**：同一建筑容量在实际基地比较集中、围合、分散、沿地形组织等不同关系。先画公共空域的大小、形状、围合和主次，再画建筑主体。沿实际道路、庭院或景观做连续剖面和透视，而不单看俯视的平面几何。
- PDF334、346、352的图面还可用来理解群体立面、柱列、空间序列和视线。用它们选取观察方法，而非复制案例布局。

这些实验是按需执行的建筑设计活动。每次选取能改变当前实际方案的少量方法，用真实图面反馈；不要把图版读后感当成交付物。

# 效果图设计忠实性

将本参考 用于图片生成阶段。

它保护已经通过 Gate C、并经 Gate D 选定视角的建筑设计。

它让图片生成模型服务于视觉表现，而不是重新设计建筑。

它以 Blender 基础渲染图作为当前视角的几何事实基准。

它不以“更漂亮”作为改变建筑几何的理由。

## 工作位置

服务对象是 建筑表现。

上游是 Gate C 已检查的 Revit 几何和 Gate D 已选定的相机。

本参考 位于 Blender 基础渲染之后、超分或 图面表达之前。

本参考 不替代 Blender 的建模、相机和透视校正工作。

本参考 不替代用户的 Gate D 相机决定。

本参考 不允许将未经 Gate C 的模型送入图片生成阶段。

## 核心边界

图片生成模型只允许改变材质。

图片生成模型只允许改变光影。

图片生成模型只允许改变天空。

图片生成模型只允许改变环境。

图片生成模型只允许改变植被。

图片生成模型只允许改变人物。

图片生成模型只允许改变氛围。

图片生成模型只允许改变视觉表现。

图片生成模型可以提升真实感、质感、色彩层次和镜头气氛。

图片生成模型可以在不遮挡关键关系的前提下补充场地生活感。

图片生成模型不负责改善建筑方案本身。


## 禁止改变的建筑事实

禁止擅自改变建筑体量。

禁止擅自改变建筑层数。

禁止擅自改变门窗主要位置。

禁止擅自改变主入口。

禁止擅自改变连廊。

禁止擅自改变柱。

禁止擅自改变关键空间。

禁止擅自增加未建成的建筑部件。

禁止擅自删除模型中已确认的建筑部件。

禁止把平屋顶改为坡屋顶或把坡屋顶改为平屋顶。

禁止增加或删除主要外挑、雨篷、平台、楼梯或坡道。

禁止把实体墙改成通透玻璃，或把主要玻璃开口改成实体墙。

禁止改变主要开口的比例、竖向分段或层间位置。

禁止改变建筑与地面、道路、台阶、入口平台或水体的基本高程关系。

禁止改变已批准的建筑轮廓、屋顶线、檐口线或主要立面节奏。

禁止利用树木、人物、车辆、阴影、裁切或景观遮住建筑错误。

禁止用生成的“创意”替代设计确认包。


## 开始前确认

读取当前 建筑表现Issue。

读取 Gate C 通过状态和用户检查意见。

读取 Gate B 已批准方案与 `DESIGN_THESIS.md`。

读取 Gate D 相机选择记录。

读取 Revit、FBX、Blender 和基础渲染的版本关系。

读取 `DECISIONS.md` 中与材料、相机、氛围有关的决定。

读取总图、平面、剖面和 Revit 三维预览。

确认 Blender 中的单位、坐标、轴向和地面关系没有错误。

确认基础图显示了要判断的入口、开口、连廊、柱和关键空间。

若基础图裁切或逆光到无法判断建筑，先修正 Blender 基础图。

不要让图像模型猜测不可见的设计。


## 建立不变项清单

从设计确认包提取建筑体量的数量、层数和相互关系。

提取建筑主入口的位置、朝向和可达方式。

提取主要门窗的分布、数量关系和楼层位置。

提取连廊、柱廊、桥、雨篷、楼梯、坡道和室外平台。

提取中庭、通高空间、展厅、活动室、教学空间或其他关键空间。

提取主要屋顶、女儿墙、檐口和地面高差。

提取不可被遮挡的关键设计特征。

提取当前相机必须看见的建筑部分。

为每一项写明来自哪一份平面、剖面、三维预览或版本。

将不确定项标为“待确认”，不将它们交给图像模型自由补全。


## Blender 基础图要求

使用 Gate C 确认的几何版本导入 Blender。

保持相机位置、方向、焦距或等效视角的记录。

保持画幅、裁切和画面用途的记录。

在 Blender 内完成正确透视和正确构图。

在 Blender 内完成建筑体量、层数、门窗、入口、连廊和柱的核对。

在 Blender 内完成基础材质、基础天空和基础光影。

基础渲染不必达到最终摄影级真实感。

基础渲染必须足以看清建筑几何。

基础渲染必须保留可判断的轮廓、开口、楼层线和入口。

基础渲染不得用极端阴影或景观遮挡关键事实。

基础渲染不得偷偷重塑 Revit 确认的几何。


## 生成提示的写法

先说明这是基于提供基础渲染的建筑可视化增强。

明确要求保留相机位置、透视、构图和建筑几何。

明确列出本轮只允许改变的视觉层。

明确列出本轮绝不允许改变的不变项。

描述材料时，描述表面质感、反射、色温、细部层次和耐候感。

描述光影时，描述时间、方向、柔硬、曝光和阴影密度。

描述天空时，描述天气、云层、色彩和可见度。

描述环境时，描述与场地逻辑一致的道路、地被或远景。

描述植被时，描述尺度、季节和不遮挡入口的边界。

描述人物时，描述尺度、活动和不遮挡关键建筑的边界。

描述氛围时，描述情绪而不是新建筑形式。

禁止使用鼓励“重设计”“重新构成”“重新布局”或“增加建筑特征”的提示语。

禁止使用会要求模型“修复建筑”“优化立面”或“添加一层”的提示语。

将“保持建筑几何不变”写成明确约束，而非可选偏好。


## 生成前最后检查

确认基础图版本与相机参数一致。

确认基础图没有使用旧模型。

确认关键入口未被裁切。

确认关键连廊和柱没有被画面边缘切断到无法判断。

确认主要门窗位置可被对照。

确认可见楼层数量可被对照。

确认设计确认包没有要求本轮改变相机或建筑。

确认提示词只要求允许的视觉变化。

确认图片输出尺寸适合后续超分或 图面表达。


## 生成工作流

接收 Blender 基础渲染图。

锁定基础图对应的相机参数与版本。

将基础图和不变项清单用于图像生成。

生成一张或一组候选效果图。

不要因生成成功而立即交付。

将生成结果与 Blender 基础图并排对照。

先检查建筑，再检查视觉质量。

如建筑事实一致，再检查材质、光影、天空、环境、植被、人物和氛围。

如变化过大，回到同一基础图重新生成。

不要用后期遮盖偏离。

选择通过的版本并记录其生成参数与时间。


## 对照检查方法

将 Blender 基础图置于左侧或作为参考层。

将生成图置于右侧或作为待核对图。

先从建筑轮廓开始比较。

再比较层数和各层水平分界。

再比较主入口、台阶、坡道和到达路径。

再比较门窗的主要位置、比例和重复节奏。

再比较连廊、柱、雨篷、外挑、阳台和主要结构线。

再比较屋顶、女儿墙、檐口和关键高差。

再比较中庭、通高、展厅或其他关键空间的可读性。

最后比较景观、人物、车辆和天空是否遮挡关键内容。

在不确定时回看平面、剖面和 Revit 三维预览。

不要仅凭整体“感觉相似”判定通过。


## 逐项视觉检查记录

记录基础图文件和版本。

记录生成图文件和版本。

记录相机参数。

记录设计确认包版本。

记录检查者和检查日期。

记录体量是否一致。

记录层数是否一致。

记录门窗主要位置是否一致。

记录入口是否一致。

记录连廊是否一致。

记录柱是否一致。

记录关键空间是否一致。

记录透视和裁切是否一致。

记录允许的材质、光影、天空、环境、植被、人物和氛围变化。

记录结论：通过、需重生成、退回 Blender、退回 工程制图 或退回 方案深化。


## 允许变化的检查

检查材质是否仅改变表面表现而不改变构件尺寸。

检查玻璃反射是否没有抹去窗框、楼层或室内外边界。

检查光影是否没有伪造新开口、柱或层间关系。

检查天空是否没有把建筑轮廓边缘生成成不真实构件。

检查环境是否与场地高程、道路和入口关系相符。

检查植被尺寸是否有助于读尺度而不是遮挡建筑。

检查人物和车辆是否符合建筑尺度与使用情景。

检查氛围、景深和色调是否没有扭曲建筑比例。

检查视觉强化没有把材料变化伪装成几何重构。


## 发现偏离时的处理

发现体量变化时，判定为不通过并重新生成。

发现层数变化时，判定为不通过并重新生成。

发现主要门窗位置变化时，判定为不通过并重新生成。

发现入口、连廊、柱或关键空间变化时，判定为不通过并重新生成。

发现基础图无法支撑准确生成时，回到 Blender 重新出基础图。

发现 Blender 基础图与 Revit 模型不一致时，返回 工程制图。

发现 Revit 模型与已批准方案不一致时，返回 方案深化。

重新生成时保留相机和几何约束，缩小只允许改变的视觉范围。

记录被拒绝图的偏离原因，避免重复同类错误。

不要把偏离图放入候选集误导用户。


## 多张图的一致性

每张图都必须可回指同一模型版本或明确的模型版本。

每张图都必须有独立的相机参数和基础图。

不同视角可以有不同光照和氛围，但不能有不同建筑事实。

同一材料在多图中可随光照呈现变化，但不应变成不同构造系统。

检查各图中的层数、入口、连廊、柱和门窗逻辑一致。

如多图之间出现矛盾，先回到 Blender 与 Revit 复核，不选择“看起来最好”的一张。


## 超分衔接

选择通过的原始生成图作为超分输入。

记录超分前图像版本。

要求超分只提高分辨率与清晰度。

超分后重新检查直线、开口、层数、柱网和立面边缘。

超分后检查纹理是否生成伪门窗、伪栏杆或伪标识。

超分后发现几何伪影时，回到未超分的通过图重新处理。

不得把超分结果当成新的设计来源。


## 图面表达衔接

交付高清效果图及其版本信息。

交付对应的 Blender 基础图和相机记录。

交付设计忠实性检查记录。

交付任何仍存的视觉限制或待确认项。

说明图像可用于汇报，但不替代平面、剖面和模型的设计证据。


## 禁止事项

禁止让图片生成模型改造建筑。

禁止让图片生成模型自行补全不可见空间。

禁止把图像生成成功当作设计忠实。

禁止跳过 Blender 基础图对照检查。

禁止用景观、人物、天空、雾、暗角或裁切掩盖偏离。

禁止在 Gate D 前代替用户选择最终机位。

禁止将存在几何偏离的图交给超分或 图面表达。

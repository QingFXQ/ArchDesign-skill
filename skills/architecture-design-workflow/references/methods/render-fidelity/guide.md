# 效果图怎么做得和方案一致

以当前可编辑模型和同机位底图为准。先想清这张图要讲什么，例如入口怎么到达、挑空空间有多高，或建筑与水岸是什么关系，再据此选机位。用户指定机位时沿用；已有合适的渲染底图可以直接接着做。

## 1. 出一张看得清建筑的底图

在 Blender 或现用的建模、渲染工具中核对当前模型。调整机位、透视和裁切，让画面里要说明的体量、楼层、入口、门窗、结构和地面关系看得清。简单的材质和光照就够起步。底图里看不清的关键部位先换机位或调整光照，也可回看模型和平剖。

## 2. 只调整这张图的表现

按需要用生图改善材质表面、光影、天气、植被、人物和远景。让配景帮助读尺度与使用方式，给入口、路线和重要构件留出视线。建筑需要改形体、立面或空间时，先改模型，再出新底图。

提示词写清本张图的表现目标和最容易生成错的部位。例如：

> 用这张底图的机位和构图。把光线调整为偏暖的午后侧光，丰富石材质感，入口前加入少量活动人物。保留楼层线、窗洞、入口台阶和连廊，人物避开入口和台阶。

## 3. 和底图并排看

先看轮廓、屋顶和楼层线，再看入口、门窗、柱、连廊、楼梯与坡道，最后看建筑与道路、地面和水体的高差。室内图核对通高、楼板和开口之间的关系。用平剖或模型复查难以判断的部位。

- 机位或透视有误，回渲染场景调整。
- 新开口、错层数或删构件等偏差，回同一底图缩小生成范围，必要时采用实模渲染。
- 发现模型本身有误，改模型，更新受影响的底图与效果图。
- 多张图逐张与各自底图对照，同时核对同一建筑的关键部位和材料。超分后再看直线、门窗、栏杆和边缘，把出现伪影的图换回可靠版本。

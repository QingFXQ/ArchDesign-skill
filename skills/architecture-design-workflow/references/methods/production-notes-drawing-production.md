# 专业操作补充

## Revit 方法优先级

首先使用原生构件。

原生构件不足时使用成熟族。

成熟族不足时使用参数化族。

参数化族无法满足时使用 In-Place 或 Mass。

再无法满足时使用脚本。

最后才使用纯几何 workaround。

选择低优先级方法时记录原因。

不得为了快速造型跳过可维护的方法。

不得把纯几何 workaround 伪装为可编辑建筑构件。

不得让低优先级方案破坏图纸一致性。


## 建模顺序

先建立项目基准、单位、标高与轴网。

再建立场地、建筑定位与主要体量。

再建立楼板、墙、屋顶与主要结构关系。

再建立楼梯、电梯、坡道与竖向交通。

再建立门窗及关键开口。

再建立主要房间、功能名称与面积数据。

再建立关键空间、剖切与视图。

最后完成图纸、标注、图名、比例与导出。

每一步都绑定方案确认包中的对应信息。

不确定处必须标为待确认并回报。


## 图纸生产要求

建立总平和必要场地视图。

建立各层平面。

建立关键剖面。

建立必要立面和三维视图。

建立房间名称、编号与面积数据。

建立图名、图号、比例、指北针、轴号与标高。

建立门窗、楼梯、电梯、洞口与屋顶的可核对表达。

使用统一视图模板、线型和可见性规则。

不要把仅供建模的辅助几何混入交付图纸。

不要将不确定构件画成已确认设计。


## 强制自检

完成关键工作后必须导出平面预览。

完成关键工作后必须导出剖面预览。

完成关键工作后必须导出三维预览。

逐项核对平面与剖面的墙体、楼板、洞口、楼梯与电梯。

逐项核对标高、层高、地形与屋顶。

逐项核对功能名称、面积与位置。

逐项核对门窗与方案确认包的基本位置。

逐项核对主要设计特征与意图卡；重要修改后并排检查固定总平、白模、剖面及必要人视点，记录保持、削弱、违背或无法判断及处理证据。

逐项核对图名、图号、比例与版本。

使用 `revit-final-check` 记录缺陷与修复结果。

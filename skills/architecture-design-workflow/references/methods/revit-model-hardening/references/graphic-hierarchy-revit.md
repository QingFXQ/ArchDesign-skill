# 图形层级：从国标四档到 Revit 落地

`revit-model-hardening` 的配套参考。解决「线型线宽没有区分」这一个具体问题。

---

## 1. 国标怎么说

**GB/T 50001-2017《房屋建筑制图统一标准》**

- 图线宽度 b 从 `1.4 / 1.0 / 0.7 / 0.5 / 0.35 / 0.25 / 0.18 / 0.13 mm` 系列中选，按图的复杂程度与比例定
- 每个图样确定基本线宽 b 后，配套线宽组为 **b / 0.7b / 0.5b / 0.25b**
- 同一图样中，同类图线的宽度应一致
- 相互平行的图线，间隙不宜小于其中的粗线宽度，且不宜小于 0.7 mm
- 注：缩微图纸不宜采用 0.18 mm 及更细的线宽

**国标没有规定“哪一类构件用哪一档”**，只规定“必须形成明确层级”。层级怎么分是设计判断，但有一条硬约束：

> **被剖切的 > 看得到的 > 辅助表达。**

---

## 2. Revit 的五层实现机制

线宽不是在一个地方设的，是五层叠加。**改错层，改不动或改了没用。**

| 层 | 位置 | 作用 | 什么时候动 |
| --- | --- | --- | --- |
| ① 对象样式 | 管理 → 对象样式 | 给「类别」一个线宽号（1–16）与线型 | **主战场**，硬化阶段只动这层 |
| ② 线宽表 | 管理 → 其他设置 → 线宽 | 定义「几号 = 多少毫米」，且**按比例分别定义** | 一般不动，除非项目已改过 |
| ③ 线型图案 | 管理 → 其他设置 → 线型图案 | 实线/虚线/单点长画线 | 轴网必须动 |
| ④ 视图样板 | 视图 → 视图样板 | 覆盖对象样式 | 有样板时，改对象样式会被样板盖住 |
| ⑤ 视图过滤器 | 视图 → 过滤器 | 按参数覆盖线宽/线型/颜色 | 家具内部再分层时用 |

**排查顺序反过来**：看到线宽不对 → 先查 ⑤ 过滤器 → 再查 ④ 样板 → 再查 ① 对象样式 → 最后查 ② 线宽表。

## 3. 实测线宽表（Revit 2021 默认，未被修改）

| 号 | 1:50 | 1:100 | 1:200 | 1:500 |
| ---: | ---: | ---: | ---: | ---: |
| 6 | 1.00 | 0.70 | 0.50 | 0.35 |
| 5 | 0.70 | 0.50 | 0.35 | 0.25 |
| 4 | 0.50 | 0.35 | 0.25 | 0.18 |
| 2 | 0.25 | 0.18 | 0.10 | 0.10 |

规律：**同一个号，比例每降一档，毫米值乘 0.7**。这不是缺陷，恰好对应国标 4.0.3「相同比例的各图样应选用相同的线宽组」——不同比例本来就该各选各的线宽组，Revit 把它自动化了。

### 由此得到的结论

**只要在四档上选对号，1:50 到 1:500 全区间都成立，不需要为不同比例再设一套。**

验算（以 6/5/4/2 映射为 b / 0.7b / 0.5b / 0.25b）：

| 比例 | 6 号 | 5 号 | 4 号 | 2 号 | 实测比值 |
| --- | ---: | ---: | ---: | ---: | --- |
| 1:50 | 1.00 | 0.70 | 0.50 | 0.25 | 1 : 0.70 : 0.50 : 0.25 ✓ |
| 1:100 | 0.70 | 0.50 | 0.35 | 0.18 | 1 : 0.71 : 0.50 : 0.26 |
| 1:200 | 0.50 | 0.35 | 0.25 | 0.10 | 1 : 0.70 : 0.50 : 0.20 |
| 1:500 | 0.35 | 0.25 | 0.18 | 0.10 | 1 : 0.71 : 0.51 : 0.29 |

偏差都在 0.05 以内。

### 唯一要留意的

1:200 / 1:500 时 2 号落到 0.10 mm，低于国标「不宜采用 0.18 及更细」。
实务上不是问题：这两个比例的平面本来就不画家具。若某张 1:200 必须带家具，**用视图过滤器把那一个视图的家具临时提到 3 号**，不要动全局对象样式。

## 4. 类别 → 档位映射（可直接套用）

| 档 | 线宽号 | 类别 | 部位 |
| --- | ---: | --- | --- |
| **b** | 6 | 墙、柱、结构柱、结构框架 | Cut |
| **0.7b** | 5 | 楼板、屋顶、天花板 | Cut |
| **0.7b** | 5 | 门、窗、幕墙嵌板、竖梃 | Cut |
| **0.7b** | 5 | 楼梯、栏杆扶手、坡道 | Cut |
| **0.5b** | 4 | 上述全部 | Projection |
| **0.25b** | 2 | 家具、家具系统 | Projection / Cut |
| **0.25b** | 2 | 轴网、标高、房间 | Projection |

设计逻辑：

- **只有被剖切的主体承担最粗档**（墙柱 = b）。楼板虽然也被剖切，但它在平面里只是一条边，给 0.7b 才不会和墙抢。
- **所有投影线统一 0.5b**。不要给窗台线、栏杆投影、台阶轮廓分别设不同号——它们是同一层信息，粗细必须一致。
- **家具退回 0.25b**。国标里家具就是“辅助表达”，和填充线同级。

### 轴网：必须改线型

轴网默认是**实线**，国标要求 **0.25b 细单点长画线**。

```csharp
var center = new FilteredElementCollector(document).OfClass(typeof(LinePatternElement))
    .Cast<LinePatternElement>().First(x => x.Name.Contains("Center"));
using (var t = new Transaction(document, "axis pattern")) {
    var o = t.GetFailureHandlingOptions();
    o.SetForcedModalHandling(false); o.SetClearAfterRollback(true);
    t.SetFailureHandlingOptions(o);
    t.Start();
    foreach (Category c in document.Settings.Categories) {
        if (c.Name != "轴网") continue;
        c.SetLinePatternId(center.Id, GraphicsStyleType.Projection);
        c.SetLinePatternId(center.Id, GraphicsStyleType.Cut);
    }
    t.Commit();
}
```

## 5. 家具为什么必须靠子类别

Revit 里**所有家具都是同一个类别** `OST_Furniture`。对象样式只能给一个类别一个线宽，所以椅子、桌子、书架**不可能**靠对象样式分开。

两条路：

| 方案 | 做法 | 代价 | 适用 |
| --- | --- | --- | --- |
| 视图过滤器 | 按族名/类型名建过滤规则，覆盖线宽 | 0（不改族），但只在该视图生效，每个视图都要加 | **先做这个** |
| 族内子类别 | 在族编辑器里给不同构件指定子类别 | 要改每个族，改动会传播到所有实例 | 长期正解，族少时才划算 |

判断标准：**族数 ≤8 且是自有族 → 改子类别；族多或来自外部库 → 先用过滤器。**

> 但要先确认一件事：国标里家具本来就该齐平在同一档（0.25b）。所谓“家具线型不对”，八成不是“家具之间没区分”，而是**家具以前混在 2–3 号里跟构件抢眼**。先把它退回最细档，问题往往就消失了。

---

## 6. 校核方法

改完必须做这三步，否则等于没改：

1. **打开线宽显示**：视图控制栏的「线宽」按钮。不开这个，屏幕上永远看不出差别——这大概也是问题一直没被发现的原因。
2. **缩到 25% 看**：如果缩到四分之一屏还能一眼分出「骨架 / 围合 / 家具」三层，层级就成了。
3. **黑白打印预览**：彩色屏幕上靠颜色区分的东西，灰度打印会全部糊掉。

## 7. 常见坑

| 坑 | 表现 | 原因 | 修法 |
| --- | --- | --- | --- |
| 改了对象样式没反应 | 视图里粗细不变 | 视图样板覆盖了 | 关掉样板的「对象样式」勾选，或改样板 |
| 只有部分构件变粗 | 同类构件粗细不一 | 有视图过滤器覆盖 | 查 ⑤ 层 |
| 改完更糊了 | 全线变粗 | 动了「线宽表」把某号改大了 | 只动对象样式，不动线宽表 |
| 轴网还是实线 | 设了线型没变 | 设的是 `Cut`，平面显示看 `Projection` | 两个都设 |
| 家具分不开 | 设了不同号没效果 | 同一类别只能一个号 | 走过滤器或子类别 |
| 1:200 图纸太淡 | 家具几乎看不见 | 2 号在 1:200 = 0.10 mm | 该视图用过滤器临时提档 |

---

## 8. 判断“是不是该改”的一条捷径

先量这个数：

> 统计全部模型类别的 `Projection` 线宽，看**众数占比**。

- 众数占比 >90% 且众数 = 1 → **层级塌陷**，必须改
- 只有 3 档且最粗档（b）不存在 → 层级不完整，必须改
- 已有 4 档但剖切线不比投影线粗 → 关系错，必须改
- 已有 4 档且关系正确 → 不要动，问题在别处（过滤器/样板/打印设置）

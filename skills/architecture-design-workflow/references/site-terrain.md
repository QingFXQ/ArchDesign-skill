# 场地与竖向专项

有显著高差、开挖、覆土、水体、屋顶使用或可达性问题时启用。保存实测来源和日期、场地边界、北向、道路及入口标高、控制线、现状建筑与实际水位。把建模假设和实测分开。主要剖面说明原地面、拟建面、建筑零点、台阶坡道、出入口衔接和排水方向。

## 土方

`design_check.py site` 输入 `schema: 1`、`units: "m"`，`earthwork.vertices` 每行为 `[x,y,原地面Z,设计地面Z]`，`triangles` 每面为三个零基节点序号。采用两表面共用的 XY 三角网。不同网格先在同一可比范围插值至共同网格；地形断点、资料空洞和边界重叠由建模者核。重复 XY 和零面积面会得到明确报错。只有证据确认 XY 和两组 Z 均相同的重节点才可在导入前合并。记录剔除的零投影面，保存原表。

每个线性三角面在高差为零处切分，取正负体积。几何填方对应成型后的地形空间，另设 `cover_m3_compacted` 记录原网格未含的屋面或其他覆土。按项目为 `material_cases` 提供 `id, suitable_fraction, compacted_per_bank, basis`。可用压实方为开挖原方 × 适填比例 × 每原方折合压实方。填方需求含独立覆土，盈亏和不适填方单列。适填率和压实系数无默认值；未给时只报几何量及需求。基础、表土、含水率、沉降损耗及分工期另辨。

## 路径

`paths` 包含 `join_tolerance_m` 及用 ID 和 `xyz` 表示的 `nodes`。`routes` 按项目指定方向（`both` 或 `forward`）、种类（`walk/ramp/stairs/lift`）和有序的节点 ID。坡度按水平投影计算，有符号，整条报告最大绝对值。`max_grade_pct` 可用作已确认上限。`joins` 为应吻合的两节点 ID 对，`return_paths` 为起点与返回目标的有向可达要求。使用同节点 ID 可以表达真实无缝连接。单线坡度和连通测试不含横坡、门槛、平台长度、护栏、消防或人流量。

临水或覆土时另确认雨水、地下水、防洪、抗浮、防水、岸线以及施工／维护条件。直接引水和独立水体分别研究。场地采用输入及可重复样例见[场地研究 JSON](../assets/site-study.json)。

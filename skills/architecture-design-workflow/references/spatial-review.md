# 建筑创作与评审

从能改变设计的一项具体关系开始。例如入口怎样接坡地、共享大厅能否服务独立开放、两岸看见什么，或屋盖怎样把反射光送入深处。用三维或剖面小样检验，保留支持取舍的实图。优先复用既有案例。新增研究看实际平剖、结构、空间序列和场地，明确要试验的动作。可用 `python scripts/resources.py design --query "坡地入口与公共大厅" --mode lexical --limit 3` 定位来源。

备选方向在平面、剖面、场地回应或总体构成中至少有一处实质区别。形式优先时先做真实尺度的实体与虚空间，核关键容量。功能优先时用运营与净宽生成分区，单列改变总体构成的轮廓。剖面优先时先定不同层高和步行连接，再回到各层平面。局部动作与整体争主时，回看群体、完整屋面、正向和侧向到达。

## 看模型

- 看鸟瞰和外部人眼，核体量比例、主从、独立退让、场地展开及第五立面。
- 沿实际路线看抵达、辨向、压缩、展开、停留和返回。以有区分度的视点判断围合、明暗、虚实、节奏、视线和上下层关系。
- 联读总平、层平与实剖，核墙、柱、楼板、洞口、真连接及高差。按任务看正常使用、独立开放、后勤和切换工况。
- 分列空间与形式潜力、场地、光、功能和运营、技术成熟度、深化难度与证据缺项。用户和教师可以得出不同的审美判断。

## 同条件横评

仅以读取方式使用历史几何。固定外部机位、投影、模型坐标、太阳天空、曝光、材料和参照尺寸。室内选可比位置，标注差异。历史量体缺少真实室内时，用剖面及相邻外部视点说明。记录统一背景、玻璃和人物做法。需要重渲染可读[视觉实验](visual-studies.md)。候选交由用户选择，必要时等待教师反馈。

## 为什么选 MIT

| 方案 | 结果 | 主要考虑 |
| --- | --- | --- |
| **MIT（已采用）** | 最短、最易读，允许使用、修改、分发与再许可 | 建筑专业用户和工具开发者都能快速确认授权范围；不额外要求 NOTICE 或修改标注 |
| Apache-2.0 | 未采用 | 含显式专利授权与商标条款，但文本长约 200 行，对以文档和脚本为主的项目偏重 |
| CC BY-NC-SA 4.0 | 未采用 | 非 OSI 认可的开源许可，禁止商用会阻碍集成与分发 |

MIT 不包含显式专利授权。若将来引入专利敏感的实现，可在保留 MIT 的同时另行说明，或重新评估许可证；变更需在提交中明确记录。

## 授权范围

MIT 覆盖本仓库的原创内容：

- `skills/architecture-design-workflow/` 下的脚本、`SKILL.md` 与 `references/` 文本。
- `scripts/`、`tests/`、`references/knowledge/` 下的原创代码与文字。
- 根目录社区文件与 `docs/`。

**不覆盖**以下内容，它们仍属于各自权利人：

- 案例库中的项目名称、建筑师姓名、图片与原文链接。本仓库只保留自行撰写的中文摘要与来源链接，未转载图片或文章正文。
- 第三方软件、字体、模型、插件与 Python 包，按各自许可证分发。
- 用户自己的项目文件、图纸、模型与其提交的反馈内容。

引用案例或规范时仍须注明来源；MIT 不改变引用的义务。
